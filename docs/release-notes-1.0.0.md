First public release of Warden, a native macOS menu bar app that detects silent changes to the config files of Claude Code, Codex and Cursor.

- Real-time monitoring of 8 default files, plus any file you add
- Fixed rules classify each change, with critical alerts for hooks, MCP servers, permissions, credentials, plugins and hidden instructions
- Plain-language explanations that name the projects you actually use, phrased on-device when Apple Intelligence is available
- Accept or Revert from a notification or the main window, with a full version history
- English and French

Requires macOS 14 or later, and has so far been tested on macOS 26. Signed and notarized. Warden contains no network code.
